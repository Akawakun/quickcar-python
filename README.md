# quickcar-python

โปรแกรมระบบจองรถเช่าแบบง่าย พัฒนาด้วยภาษา Python  
ผู้ใช้สามารถเลือกประเภทรถ ระบุจำนวนวันที่เช่า และคำนวณค่าเช่ารวมได้

## การวิเคราะห์กลุ่มเป้าหมาย

- นักเรียน นักศึกษา หรือผู้ที่ต้องการเช่ารถ
- ผู้ที่ต้องการคำนวณค่าเช่ารถอย่างรวดเร็ว
- ผู้ใช้ที่ต้องการระบบจองรถที่ใช้งานง่าย

## ฟังก์ชันของระบบ

1. **เลือกประเภทรถ**
   - รถเก๋ง
   - รถกระบะ
   - รถตู้
   - สามารถกรอกเป็นหมายเลขหรือชื่อประเภทรถได้

2. **คำนวณค่าเช่า**
   - รับจำนวนวันที่ต้องการเช่า
   - คำนวณราคาตามประเภทของรถ
   - แสดงราคารวม

3. **แสดงข้อมูลการจอง**
   - แสดงประเภทรถที่เลือก
   - แสดงจำนวนวันที่เช่า
   - แสดงราคารวม

## การทำงานของระบบ

ผู้ใช้เลือกประเภทรถ → กรอกจำนวนวันที่เช่า → คำนวณราคา → แสดงข้อมูลการจอง → เลือกว่าจะทำรายการใหม่หรือออกจากโปรแกรม
